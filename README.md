# Portal do Colégio Estadual Cívico-Militar Vereador Luiz Zanchim

Site oficial do portal escolar com:

- Achados e Perdidos
- Reclamações (com filtro de linguagem)
- Sugestões de melhoria
- Notícias
- Calendário escolar
- Painel administrativo com resumo por IA (protótipo)

## Acessar o site

1. Vá em **Settings** → **Pages**
2. Em **Source**, escolha **Deploy from a branch**
3. Branch: **main** / pasta: **/ (root)**
4. Salve

Depois de alguns minutos o site fica em:

**https://qeloize-elyot.github.io/escola/**

## Login de demonstração (admin)

E-mail: `admin@ccm.local`

## Tecnologias

HTML, CSS e JavaScript puro (frontend). Dados salvos no navegador (localStorage).
